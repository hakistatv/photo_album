Photo Album

Flash the firmware straight from your browser -- no ESP-IDF install needed.

Your browser doesn't support Web Serial. Open this page in Chrome or Edge on a desktop instead. Web Serial is blocked here -- this page needs to be loaded over https:// (which it is, if you're reading this at github.io), from Chrome or Edge on desktop.

Before you start

  1. Use Chrome or Edge on a desktop/laptop (Web Serial isn't available on mobile or in Safari/Firefox).
  2. Plug the board in over USB.
  3. Click Connect & Install above and pick the board's serial port from the browser's device picker.
  4. If this is the first time flashing this board with this firmware (or it previously ran different firmware), tick Erase device when prompted -- it clears out any leftover settings from before.

Once flashing finishes, the device reboots and starts its own Wi-Fi access point (photo-album / qrcode123 by default). See the project README for how to use it.

Firmware is rebuilt automatically from source on every push to main -- this always installs the latest build.
